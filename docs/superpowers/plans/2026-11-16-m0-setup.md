# M0 — Setup del progetto: piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** passare dal repository-laboratorio a una base di produzione: solo le scelte del lab, home e gallery vere, lab fuori dalla build, controlli di qualità, CI e anteprime su Cloudflare Pages.

**Architecture:** le scelte del lab diventano moduli in `src/lib/` senza varianti (`reveal`, `loader` + `monogram`, `gallery`, `card`, `footer`), montati da due pagine di produzione (`/` e `/gallery/`). I contenuti finti escono dai componenti e vanno in `src/content/` (il futuro adattatore Sanity). Il lab si sposta in `src/lab/` e viene iniettato da una piccola integrazione Astro solo in sviluppo o con `LAB=1`; la build di produzione non lo contiene.

**Tech Stack:** Astro 7 statico, Tailwind v4, GSAP + ScrollTrigger, Lenis, Playwright, Prettier, `@astrojs/check`, GitHub Actions, Cloudflare Pages.

**Spec:** `docs/superpowers/specs/2026-11-15-stack-e-lab-design.md`, roadmap `docs/superpowers/plans/2026-11-16-roadmap-v1-v2.md` (M0 e decisioni D1–D7), `CLAUDE.md`.
